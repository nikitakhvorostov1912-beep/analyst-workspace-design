# 03 — Delivery Modes: EPF vs CFE

## Сравнение режимов

| Параметр | 🪶 EPF Lite | ⚡ CFE Full |
|----------|-------------|-------------|
| **Файл** | `АналитикLite.epf` ~3 MB | `АналитикПлюс.cfe` ~8 MB + Install-script |
| **Установка** | Двойной клик → "Файл → Открыть" | DESIGNER LoadConfigFromFiles |
| **Время установки** | 30 сек | 2-3 мин (требует доступ к Конфигуратору) |
| **Влияние на конфигу** | Никакого | Расширение (есть в списке расширений) |
| **Требует доработки конфигурации** | Нет | Да (CFE-расширение) |
| **Сервер работает** | Пока форма открыта | 24/7 как HTTP-сервис |
| **Capabilities** | 8 базовых (+3 опц. через доп. установку) | 23 (все 11+12 extended) |
| **HMAC SSO** | Manual (ввод токена) | Automatic (от 1С пользователя) |
| **Подписки на события** | Нет | Да (5+) |
| **Перехват методов** | Нет | Да (через `&Перед` / `&После`) |
| **Регламентные задания** | Нет | Да |
| **Активити-трекинг** | Нет | Да (регистры МониторингАктивности) |
| **Posting trace** | Нет | Да (детальная трассировка проведения) |
| **Risk для prod базы** | Минимальный (внешняя обработка) | Средний (расширение влияет на работу) |
| **Use case** | Разовый аудит, demo, restricted клиент | Постоянное использование, full feature |

## Use cases

### EPF Lite — когда выбирать

✅ **Разовый аудит у клиента** — пришёл, разобрался, ушёл, ничего не оставил

✅ **Демо** — показать продукт без установки на конфигу

✅ **Restricted клиент** — внутренние политики запрещают менять конфигу

✅ **Quick start** — впервые знакомитесь с продуктом

✅ **Тестирование на копии prod базы** — без рисков

✅ **Когда нет доступа к Конфигуратору** — только режим Предприятия

### CFE Full — когда выбирать

✅ **Постоянное использование** — аналитик работает с этой базой каждый день

✅ **Углублённый аудит** — нужен Activity Stream + Posting Trace + история

✅ **Команда из 2+ аналитиков** — HMAC SSO даёт SSO под каждого

✅ **Регламентные задачи** — auto-export отчётов, ежедневные алерты

✅ **Интеграция с DevOps** — scheduled jobs триггерят CI/CD пайплайны

✅ **Кастомные команды в УТ/ERP** — аналитик хочет видеть "Открыть в Аналитике" в контекстном меню документов

## Артефакт A — `АналитикLite.epf` детально

### Структура (внутри обработки)

```
АналитикLite.epf
├── Формы/
│   ├── ОсновнаяФорма/             ← launcher window
│   │   ├── ОсновнаяФорма.xml
│   │   └── ОсновнаяФорма.Модуль.bsl
│   └── НастройкиToken/            ← ручной ввод HMAC токена
│       ├── ...
├── Общие модули/
│   ├── АП_MCPServerHTTP           ← наш MCP Toolkit (HTTP сервер)
│   ├── АП_HTTPКоннектор           ← embedded Connector
│   ├── АП_AuthHMAC                ← валидация токена от веб-приложения
│   └── АП_CapabilityResponse      ← возвращает 8 capabilities
└── Макеты/
    └── Логотип.png
```

### Workflow первого запуска

```
1. Аналитик: двойной клик на АналитикLite.epf
2. Платформа: "Открыть как внешнюю обработку?" → Да
3. Форма открывается:
   ┌────────────────────────────────────────┐
   │ Аналитик 1С — Lite режим                │
   │ ─────────────────────────────────────  │
   │ MCP Server: ⚪ Не запущен               │
   │                                        │
   │ Порт: [6010]                           │
   │ HMAC секрет: [────────────] [генерир.] │
   │                                        │
   │ [🚀 Запустить сервер]                  │
   │                                        │
   │ После запуска откройте веб-приложение  │
   │ с URL: analyst://open?endpoint=...     │
   │ ─────────────────────────────────────  │
   │ Доступно в Lite режиме:                │
   │ ✓ Чтение данных                        │
   │ ✓ Просмотр кода (read-only)            │
   │ ✓ Журнал регистрации                   │
   │ ✓ Анализ прав                          │
   │                                        │
   │ Хотите больше? [Установить CFE-расш.] │
   └────────────────────────────────────────┘
4. Жмёт "Запустить" → MCP слушает :6010
5. Жмёт "Открыть веб-приложение" → Electron открывается
6. Веб-приложение через HMAC получает endpoint MCP
7. Веб-приложение начинает работу с capabilities=[8 basic]
8. Если форма закрывается — сервер останавливается (с предупреждением)
```

### Особенность: ручной HMAC

В EPF режиме HMAC SSO **недоступен** (нет sustained сессии). Решение:
- Аналитик жмёт "Сгенерировать секрет" → форма генерирует случайный 32-байтовый ключ
- Копирует ключ → вставляет в Settings веб-приложения
- При каждом запуске EPF нужно ввести этот ключ заново

Это **trade-off за лёгкость установки**. Кому нужен seamless flow — выбирают CFE.

### Workflow первого запуска CFE

```
1. Аналитик качает АналитикПлюс.cfe + Install-АналитикПлюс.ps1
2. Запускает Install-АналитикПлюс.ps1
3. Скрипт спрашивает:
   - Путь к базе 1С (по умолчанию из .v8-project.json)
   - Логин/пароль (для DESIGNER)
4. Скрипт:
   - Запускает DESIGNER в фоне
   - LoadConfigFromFiles с расширением
   - UpdateDBCfg --extension
   - Останавливает DESIGNER
5. После установки → платформа предупреждает "Перезапустить?"
   Аналитик: "Да"
6. После перезапуска:
   - Регламентное задание АП_ПриНачалеРаботыСистемы запускает HTTP-сервис
   - HTTP-сервис слушает :6010/mcp 24/7
   - Подписки на события активны
7. Аналитик открывает Electron-приложение
8. Electron видит что MCP уже работает на :6010
9. Аналитик: "Добавить подключение" → endpoint=http://localhost:6010/mcp
10. Backend делает initialize → получает 23 capabilities → mode="cfe"
11. UI активирует все CFE-модули (Activity Stream, Posting Trace, ...)
12. Через HMAC — auto-login под 1С-пользователем
```

### HMAC SSO в CFE

```python
# Backend поток
1. Frontend → POST /chat { sessionId, query }
2. Backend проверяет session.hmac_token
3. Если есть — извлекает username, base_id, expires
4. Если истёк — frontend получает 401 → редирект на /auth/refresh
5. Электрон через protocol handler analyst:// получает новый токен от CFE
6. Frontend получает новый сессионный токен → продолжает работу

# В 1С CFE общий модуль АП_AuthHMAC
Функция СгенерироватьТокен() Экспорт
    Данные = Новый Структура;
    Данные.Вставить("username", ИмяТекущегоПользователя());
    Данные.Вставить("base_id", СтрокаСоединенияИнформационнойБазы());
    Данные.Вставить("expires", ТекущаяДатаСеанса() + 3600);

    JSONДанные = ЗаписьJSON(Данные);
    Подпись = HMAC_SHA256(JSONДанные, СекретныйКлюч);

    Возврат Base64(JSONДанные) + "." + Base64(Подпись);
КонецФункции
```

## Миграция между режимами

### EPF → CFE (upgrade)

**Сценарий:** аналитик начал с EPF, понял что нужен Activity Stream, хочет перейти на CFE без потери истории.

```
1. Аналитик качает АналитикПлюс.cfe
2. Запускает Install-АналитикПлюс.ps1
3. Перезапускает 1С
4. CFE автоматически запускает HTTP-сервис на :6010
   ⚠️ ВАЖНО: если EPF тоже работал — он отвалится (порт занят)
5. В Electron приложении: Settings → MCP → Транзит → "Обновить capabilities"
6. Backend делает re-handshake → видит mode="cfe", 23 features
7. Connection.mode меняется на "cfe", capabilities обновляются
8. Frontend перерисовывает: disabled панели становятся активными
9. История сессий сохраняется (привязана к Connection.id)
```

### CFE → EPF (downgrade, редко)

**Сценарий:** клиент попросил убрать CFE временно.

```
1. В 1С: Конфигуратор → Расширения → отключить АналитикПлюс
2. Запустить EPF АналитикLite.epf
3. В Electron: Settings → "Обновить capabilities"
4. Mode меняется на "epf", capabilities сужаются до 8
5. Frontend отключает CFE-модули, показывает UpgradeCTA вместо них
6. История сохраняется
```

### Forward compatibility

Backend хранит `historical_capabilities` per Connection — для исторического анализа когда что было доступно. Это не критично для MVP, но полезно для отчётов.

## Установочные скрипты

### `Install-АналитикПлюс.ps1` (PowerShell для CFE)

```powershell
param(
    [string]$BasePath = $null,
    [string]$User = "Администратор",
    [string]$Password = "",
    [string]$PlatformPath = "C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe"
)

# 1. Найти .v8-project.json если BasePath не задан
if (-not $BasePath) {
    $projectFile = Get-ChildItem -Path . -Filter ".v8-project.json" -Recurse | Select-Object -First 1
    if ($projectFile) {
        $config = Get-Content $projectFile.FullName | ConvertFrom-Json
        $BasePath = $config.databases[0].path
    }
}

if (-not $BasePath) {
    Write-Host "Укажите путь к базе через -BasePath или создайте .v8-project.json" -ForegroundColor Red
    exit 1
}

# 2. Извлечь CFE из текущей директории
$cfeFile = ".\АналитикПлюс.cfe"
if (-not (Test-Path $cfeFile)) {
    Write-Host "Файл АналитикПлюс.cfe не найден в текущей директории" -ForegroundColor Red
    exit 1
}

# 3. Запустить DESIGNER в batch режиме
$logFile = ".\install-АналитикПлюс.log"

& $PlatformPath DESIGNER `
    /F $BasePath `
    /N $User `
    /P $Password `
    /DisableStartupMessages `
    /LoadCfg $cfeFile `
    /UpdateDBCfg --extension=АналитикПлюс `
    /Out $logFile

if ($LASTEXITCODE -eq 0) {
    Write-Host "✅ АналитикПлюс установлен в базу $BasePath" -ForegroundColor Green
    Write-Host "🔄 Перезапустите 1С для активации расширения" -ForegroundColor Yellow
    Write-Host "📊 После перезапуска MCP-сервис запустится автоматически на :6010"
} else {
    Write-Host "❌ Ошибка установки. См. $logFile" -ForegroundColor Red
    Get-Content $logFile -Tail 20
    exit 1
}
```
