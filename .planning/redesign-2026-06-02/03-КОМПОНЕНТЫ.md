## 3.1 `Alert` — единая система сообщений (НОВЫЙ, лечит F-04)

Сейчас в проекте **пять** разных поверхностей ошибок: `BackendDownBanner`,
`ConnectionStatusBanner`, `components/ui/ErrorBanner`, inline `⚠ {message}` в
`AssistantMessage`, тосты, `FieldError`. Свести к одному примитиву.

**Файл:** `frontend/components/ui/Alert.tsx`

```tsx
type AlertTone = "info" | "success" | "warning" | "error";
interface AlertProps {
  tone: AlertTone;
  title: string;
  description?: React.ReactNode;
  actions?: React.ReactNode;     // кнопки (Повторить / Что это значит?)
  icon?: LucideIcon;             // дефолт по tone
  onClose?: () => void;          // если задан — крестик
}
```

**Спека:**
- Контейнер: `flex gap-3`, `rounded-[10px]`, `border`, паддинг `14px 16px`.
- Тоны: bg `--{tone}-12`, border `--{tone}-40` (или `color-mix` 40%), title — `--fg-1`,
  description — `--fg-2/3`. Иконка `18px` цвета `--{tone}`.
- **Иконки из lucide, не emoji:** error→`AlertCircle`, warning→`AlertTriangle`,
  success→`CheckCircle2`, info→`Info`.
- Действия — слот `actions` снизу, кнопки высотой 32px.

**Заменить им:**
- `AssistantMessage` inline error (`⚠ {message}`) → `<Alert tone="error" title=… />` без emoji.
- `ErrorBanner`, `BackendDownBanner`, `ConnectionStatusBanner` — переписать как тонкие
  обёртки над `Alert` (или заменить вызовы). Один визуальный язык на все ошибки.
- `settings/page.tsx` блок `border border-red-800` → `<Alert tone="error" />`.

## 3.3 Провенанс ответа — «Грунт ответа» (НОВЫЙ, лечит F-02 · critical)

Ядро доверия. Сейчас источник = крошечный ярлык `AnswerSources` (10.5px), а сам
запрос спрятан в свёрнутом `ToolTrace`. Промотать провенанс в первый класс.

**Файл:** `frontend/components/chat/AnswerProvenance.tsx`
Заменяет/поглощает `AnswerSources.tsx`. Рендерится под текстом ответа в `AssistantMessage`.

```tsx
interface AnswerProvenanceProps {
  toolCalls: ReadonlyArray<ToolCallRecord>;  // из message.tool_calls
  sources: AnswerSource[];                    // deriveAnswerSources()
}
```

**Спека — две части (см. варианты A и B в референсе, секция 07):**

1. **Полоса «Грунт»** (всегда видна, если были tool_calls):
   - `flex items-center gap-2`, фон `--accent-08`, бордер `--accent-22`, `rounded-[8px]`, паддинг `8px 11px`.
   - Точка-маркер `--accent` + текст: `Грунт: N запрос(а/ов) к базе` + ссылка-кнопка `показать`.
   - Иконки источников (База/Типовая/ИТС) — из `lucide` (`Database`/`Boxes`/`BookMarked`).
2. **Раскрытие** (по клику «показать»):
   - Карточка с самим запросом к 1С на `--code-bg` (моно, JB Mono 10.5–12px) и
     результатом/длительностью. Это то, что сейчас прячется в `TraceSummary` — поднять
     его в один клик у ответа, а не в подвал.

`ToolTrace` оставить для полной трассировки (все шаги модели), но он больше **не
единственный** способ проверить ответ. Провенанс самодостаточен.

## 3.6 Шапка — статус ≠ действия (изменить, лечит F-03)

**Файл:** `frontend/components/shell/Header.tsx`

Сейчас правый блок — 10 иконок 15px в ряд (Update, Knowledge, Аноним, Модель,
Search⌘K, Activity, BookOpen, HelpCircle, Theme, Settings). Разделить на группы:

1. **Статус** (центр или левее) — живой индикатор: `База: {name} ●` + `Модель: {name}`
   + `Аноним` (если вкл). Это `ChannelSelector` + `ModelBadge` + `AnonymizationStatus` —
   сгруппировать в один блок «состояние», единый стиль pill.
2. **Действия** (справа) — `Search ⌘K`, `Настройки` (Settings), `Тема`.
3. **Справку объединить в одно меню** `?` (dropdown): «Диагностика», «Гайд аналитика»,
   «О приложении» — **с текстовыми подписями**, а не три неразличимые иконки
   (`Activity`/`BookOpen`/`HelpCircle`). Использовать `components/ui/dropdown-menu`.
4. `UpdateBanner` / `KnowledgeBadge` — оставить, но убедиться, что они не в общей куче
   иконок: Update — только когда есть апдейт; Knowledge — в блок статуса.
- Все иконки-кнопки: цель ≥ 32px, `aria-label` обязателен (уже есть — сохранить).
