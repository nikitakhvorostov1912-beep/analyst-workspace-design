## Очерёдность

### Спринт 1 — Быстрые победы (текст + основа)
Дёшево, эффект сразу везде.
1. **Дизайн-токены** (`01`) — новые значения dark+light, удалить мёртвые accent-темы,
   токенизировать скроллбар. _Самопроверка 01.9._
2. **Голос и тон** (`02`) — таблица замен, глоссарий. Правки `CLAUDE.md`.
3. **`Alert`** (3.1) + перевод всех ошибок на него, убрать emoji и жаргон (F-04).
4. **Композер** (3.5) — убрать счётчик токенов, один hint, убрать дубль brand-tick (F-09).

### Спринт 2 — Доверие (ядро ценности)
5. **«Грунт ответа»** (3.3) — провенанс первым классом (F-02). Самая важная фича.
6. **Сообщение ассистента** (3.4) — аватар, время, hover-действия (F-06).
7. **Карточка-результат** (3.7) — один заголовок, усечение в чип, зебра (F-08);
   трейс ok/error без радуги (01.6).

### Спринт 3 — Структура и чистота
8. **Шапка** (3.6) — статус ≠ действия, справка в одно меню (F-03).
9. **Снизить стенсил-шум** (F-05) — оранжевый только на действие, eyebrow дозированно.
10. **Единый пустой экран** (3.2) — один компонент + один источник примеров (F-12).

### Спринт 4 — Рост и доступность
11. **Онбординг** (F-07) — ценность вперёд, развилка ролей, память тумблером.
12. **Сайдбар** (3.8) — поиск, закрепление, переименование, свёрнутый режим (F-11).
13. **Аудит доступности** по чек-листу ниже как Definition of Done.

## Критерии приёмки

### После Спринта 1
- [ ] `getComputedStyle(body).backgroundColor`: dark `rgb(12,13,16)`, light `rgb(241,239,232)`.
- [ ] Переключение темы не оставляет «полусветлых» зон (см. грабли transition в 01.9).
- [ ] grep по UI не находит: `Напиши`, `Задай`, `Проверь связь`, `backend`, `канал`, emoji `⚠`.
- [ ] Все ошибки рендерятся через `Alert`, один вид; есть путь к решению.
- [ ] Под композером нет «N / 4000 ТОКЕНОВ».

### После Спринта 2
- [ ] Под ответом с tool_calls видна полоса «Грунт»; «показать» открывает запрос к 1С.
- [ ] У ответа ассистента: аватар-глиф, время, длительность, действия копировать/повторить.
- [ ] `TableCard`: усечение видно в шапке карточки; числа `tabular-nums` справа; зебра.
- [ ] Трейс-чипы только нейтральный/error (нет blue/green/purple).

### После Спринта 3
- [ ] В шапке ≤ 4 действия-иконки; справка — одно меню с подписями; цели ≥ 32px.
- [ ] На главном/чате есть один очевидный акцент-CTA; нет «ковра» микролейблов.
- [ ] Главная и пустой чат используют один `EmptyState` + один список примеров.

### После Спринта 4
- [ ] Онбординг: первый экран без техжаргона; развилка ролей; «настроил ИТ» ведёт в работу.
- [ ] Сайдбар: поиск работает; чат можно закрепить/переименовать; свёрнутый режим не пустой.

## Чек-лист доступности (Definition of Done на каждое изменение)
- [ ] Контраст текста ≥ 4.5:1 (крупный ≥ 3:1) в **обеих** темах. Проверять реальные пары.
- [ ] Focus-ring виден на всех интерактивных элементах: `outline: 2px solid var(--accent); outline-offset: 2px`.
- [ ] Полный путь с клавиатуры: Tab по порядку, Enter/Esc в диалогах, ⌘K/Ctrl+K — палитра.
- [ ] Цели нажатия ≥ 32px; иконки-кнопки имеют `aria-label`.
- [ ] Статус = цвет + форма + текст (не только цвет).
- [ ] `aria-live` на стриме ответа и тостах; осмысленный порядок чтения скринридером.
- [ ] `prefers-reduced-motion` уважается (не сломать существующий блок в `design-tokens.css`).

## Тестирование
- **Юнит/компонентные:** `cd frontend && pnpm vitest` — обновить снапшоты/строки там,
  где менялся копирайт или DOM (`__tests__` рядом с компонентами). Тесты, проверяющие
  старый текст («Задай первый вопрос», «ТОКЕНОВ»), привести к новому.
- **E2E:** `pnpm playwright test` — проверить, что онбординг (новый поток), отправка
  вопроса, рендер карточки и ошибок проходят. Селекторы `data-testid` сохранять
  (`composer-hub`, `send-button`, `attach-button`, `thread-empty`, `trace-toggle`,
  `result-truncated-banner` и т.д.) — не удалять, чтобы тесты жили.
- **Линт/типы:** `pnpm lint && pnpm tsc --noEmit` (или `next build`) — без ошибок.
- **Глазами:** прогнать оба ключевых экрана (главная, чат с карточкой и ошибкой) в
  dark и light, сверить с `reference/Аудит-и-Дизайн-система.html`.

- Не вводить новые термины вне глоссария `02.2`.
- Не плодить новые варианты компонентов — переиспользовать `components/ui/*`.
