## 0. Что это за проект (контекст)

**Аналитик** — десктопное приложение (Electron) для аналитиков и консультантов 1С.
Пользователь задаёт вопрос обычными словами → языковая модель сама подбирает
инструменты, обращается к базе 1С (через MCP-обработку), выполняет запросы и
возвращает ответ + карточки-результаты (таблицы, метрики, графики, объекты).

**Три источника знаний**, которыми отвечает ассистент:
1. **База** — данные пользователя в его 1С (документы, остатки, журнал регистрации).
2. **Типовая** — как устроена типовая конфигурация (УТ / ERP / КА / БП).
3. **ИТС** — методики, стандарты, инструкции 1С.

### Стек (фактический)
- **Frontend:** Next.js (App Router), React 18, TypeScript.
- **Стили:** Tailwind v4 (`@theme inline` маппинг в `frontend/app/globals.css`) +
  CSS-переменные в `frontend/styles/design-tokens.css`. Допустим и legacy-синтаксис
  `bg-[var(--bg-1)]`, и utility-классы `bg-bg-1` — они эквивалентны.
- **Компоненты:** shadcn-подобные примитивы в `frontend/components/ui/`.
- **Иконки:** `lucide-react`. **Никаких emoji** (бренд-гайд прямо запрещает).
- **Бренд:** Stencil/Mono. Signal `#FF6A3D`, Ink `#15161A`, Sand `#F3F1EC`.
  Шрифты: IBM Plex Mono (лого/дисплей), IBM Plex Sans (UI/тело), JetBrains Mono
  (данные/мета). Источник правды бренда: `.brand/BRAND.md`.

### Темы
Две равноправные: **dark** (по умолчанию) и **light (Sand)**, через
`<html data-theme="light">`, сохраняется в `localStorage["analyst-theme"]`.
Оба варианта обязаны проходить приёмку.

## 1. Главный принцип реализации

**Это рефактор существующего кода, а не переписывание с нуля.**
Большинство правок — это:
1. Изменение значений CSS-переменных (`design-tokens.css`) — даёт эффект сразу везде.
2. Унификация дублирующихся компонентов (ошибки, пустые состояния) в один.
3. Точечные правки разметки/копирайта в конкретных файлах.

Не ломай работающую логику (SSE-стрим, стор сессий, обработку ошибок бэкенда,
анонимизацию). Меняй **представление**, сохраняя поведение, если в ТЗ явно не
сказано менять поток (онбординг — единственное место, где меняется структура).

### Бренд-инварианты (НЕ нарушать)
- Signal `#FF6A3D` не меняется между темами (в light допускается «глубже» — см. 01).
- Glyph (BrandMark) — всегда тёмный squircle + белая «А» + оранжевый маркер.
- Логотип АНАЛИТИК — IBM Plex Mono 700 uppercase. Без курсива/skew/glow/emoji.
- Запрещено: градиенты на signal, gradient-text, glass-morphism, сторонние оранжевые.

## 3. Definition of Done (общий)

Изменение принято, только если:
- [ ] Работает в **обеих** темах (dark + light), контраст текста ≥ 4.5:1 (крупный ≥ 3:1).
- [ ] Весь интерактив доступен с клавиатуры, виден focus-ring (2px Signal, offset 2px).
- [ ] Цели нажатия ≥ 32px (иконки-кнопки), хит-зоны ≥ 44px где возможно.
- [ ] Нет emoji в UI; статусы передаются цвет + форма + текст, не только цветом.
- [ ] `prefers-reduced-motion` уважается (уже настроено в `design-tokens.css` — не сломать).
- [ ] Существующие тесты (`vitest`, `playwright`) проходят; обновлены при изменении DOM/копирайта.
- [ ] Нет ошибок в консоли и в `tsc`/`eslint`.
