## 2.1 Единый регистр: «вы», строчное, в потоке

Аудитория — занятые специалисты 1С (B2B). Регистр — **«вы» со строчной буквы**
в середине фраз («…к которым вы обращаетесь»), глаголы спокойно-инструктивные.
Никакого «ты», никакого фамильярного «проверь/напиши», никакого казённого «Вы»
с заглавной в середине предложения.

**Тон:** уважительный, по делу, без жаргона. Ошибки — без обвинения пользователя,
с путём к решению.

## 2.2 Глоссарий (одно слово на сущность)

Использовать строго эти слова в UI. Внутренние термины («канал», «session»,
«LLM», «MCP», «backend») в видимом тексте **запрещены**.

| Сущность | Говорим | НЕ говорим |
|---|---|---|
| Источник данных 1С | **База** | канал, подключение, эндпоинт |
| Диалог | **Чат** | сессия, тред |
| Долгая память | **Память** | обучение, learn |
| Языковая модель | **Модель** | LLM, движок, ИИ-провайдер |
| Серверная часть | **Сервис** (или просто не упоминать) | backend, сервер |
| Поток ответа | (не упоминать механику) | SSE, стрим |
