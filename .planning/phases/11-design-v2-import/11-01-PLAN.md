## Risks

- **Tailwind 4 синтаксис** отличается от 3.x — `theme.extend` теперь через `@theme` в CSS, не в JS config. Проверить актуальную документацию **до** EDIT.
- **CSS variable propagation** через `:root, .dark` — Next.js может сбросить `.dark` класс на client (HTML уже имеет `class="dark"` из layout.tsx — проверить)
- **Tests assertions** на конкретные hex значения — упадут после миграции в variables. Mitigation: оставить hex в первой версии, миграция в classes — постепенно в 11.2+
