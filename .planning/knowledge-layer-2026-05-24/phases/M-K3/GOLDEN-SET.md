# Golden-set приёмки grounding (#39)

> Набор эталонных вопросов аналитика для приёмки «Объяснителя» (гейты G0–G3,
> см. `../../ACCEPTANCE-explainer.md`). Каждый вопрос → ожидаемый grounded-ответ,
> сверяемый с ФАКТАМИ графа `pilot.db` (не с прозой карточки).
>
> **Статус:** засеяно валидированными примерами из демо 2026-06-01.
> 🟡 **ТРЕБУЕТСЯ ВЛАДЕЛЕЦ:** добавить реальные вопросы из практики внедрений
> (раздел «TODO — из практики») — это и есть суть #39, синтетика её не заменит.

## Как пользоваться

1. Прогон: `python -m scripts.demo_grounding --channel <ch> --qname <qname>`
   (или живой чат с ключом MiMo) → сверить ответ с колонкой «Ожидаемые факты».
2. Гейты: **G0** (честность — не выдумывает, признаёт пробел) и **G2**
   (grounding — числа/списки из графа) важнее **G1** (полнота формулировки).
3. Критерий PASS: факты совпали с графом, нет галлюцинаций, при пробеле — честное «не нашёл».
