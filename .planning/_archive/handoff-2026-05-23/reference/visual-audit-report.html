  5 блокеров — чинить до релиза

Каждый из этих пяти ломает работу в light-теме либо ломает бренд-консистентность. Все — детерминированные, локальные, чинятся быстро.

BLOCKER B-1

CSS-переменная --bg-hover используется в 8 файлах, но нигде не определена

Компоненты резолвят --bg-hover в unset → inherit — невидимый hover. Особенно фатально в light-теме (Sand): hover пропадает полностью. Затронуты главный селектор баз 1С, все dropdown'ы, command palette, status row.
SHELL/CHANNELSELECTOR.TSX UI/DROPDOWN-MENU.TSX UI/COMMAND.TSX +5 ФАЙЛОВ
Добавить в :root и [data-theme="light"]: --bg-hover: var(--bg-2); — 5 минут, чинит hover на ~30% интерактивных элементов.
BLOCKER B-2

30+ мест с хардкод-цветами text-red-400, bg-red-950, text-blue-400

В status, insights, всех cards и формах настроек — старая Tailwind-палитра вместо --success / --warning / --error / --accent. В light-теме ярко-розовый текст на песочном фоне, контраст местами < 3:1.
~30 МЕСТ CARDS/LOGCARD CARDS/TABLECARD CHAT/BANNER UI/BUTTON DESTRUCTIVE
Codemod: text-red-* → text-[var(--error)], bg-red-950 → bg-[var(--error-12)], text-blue-400 → text-[var(--accent)]. 2–3 часа, чинит light-тему целиком.
BLOCKER B-3

Запрещённые технические термины — «MCP», «Channel», «Tool calls» — видны аналитику

В /insights KPI «Tool calls», «Errors», «Rate». В /status — «Канал», «Версия MCP», «обработка MCP_Toolkit». В MCPConnectionForm поле «Канал» с placeholder tranzit-prod. Пользователь — бизнес-аналитик, не разработчик.
INSIGHTS STATUS MCPCONNECTIONFORM ABOUT
«Tool calls» → «Запросов в 1С». «Channel» → «База 1С». «Версия MCP» → expert-блок. «Errors / Rate» → «Ошибок / % ошибок».
BLOCKER B-4

Двойной заголовок «Модель ИИ» + дубль описания в LLMConfigForm

Заголовок секции «Модель ИИ» из /settings + label «Модель ИИ» внутри формы → визуально два H. SelectItem с flex flex-col делает trigger двухстрочным — текст центрируется неровно. Описание под селектом дублирует описание в дропдауне.
SETTINGS/PAGE.TSX:108 SETTINGS/LLMCONFIGFORM.TSX:443 VISUAL DUPLICATE
Убрать внутренний label. SelectItem рендерить плоско — label · description в одну строку. Описание под селектом удалить.
BLOCKER B-5

Light-тема катастрофически сломана в 8+ местах

Хардкод-краснота из B-2 + неопределённый --bg-hover из B-1 + хардкод scrollbar #262626 на песочном фоне + bg-black/60 overlay становится грязно-серым + focus:bg-[var(--bg)] на bg-0 (focus исчезает) + ConnectionStatusBanner = тёмно-красный квадрат на песке.
8+ ТОЧЕК SCROLLBAR DIALOG OVERLAY BANNER
После B-1 / B-2 — обход экранов в light-теме, фикс scrollbar через токены, замена bg-black/60 на color-mix(var(--bg-0) 60%, transparent).

  Топ HIGH — 6 находок, ритм и feedback

Не валят релиз, но именно от них зависит ощущение «полированности» продукта.

HIGH H-1

Destructive-кнопка не из бренда

bg-red-800 text-white hover:bg-red-700 в button.tsx:20. Применяется на «Удалить LLM-конфиг», «Удалить подключение», «Сбросить базу» — все деструктивные действия выглядят чужеродно в Stencil.
Variant destructive: bg-[var(--error-20)] text-[var(--error)] border border-[var(--error-40)]; primary destructive — solid --error.
HIGH H-2

Feedback от «Тест» только через toast — пользователь моргнул и пропустил

В LLMConfigForm и MCPConnectionForm результат теста — единственный сигнал — всплывающий toast на 3 сек. Если аналитик отвёл взгляд, он не знает, прошёл ли тест.
Inline-результат рядом с кнопкой: StencilChip с success/error + ms + tool count. Toast — дополнительно, не вместо.
HIGH H-3

Settings — три разных padding на одной странице

Базы 1С / Модель ИИ — p-5. Link-cards (Memory / Insights / Skills) — p-4. Внутренний контейнер MCPConnectionForm — p-4. rounded-md рядом с rounded-lg. Вертикальный ритм рваный.
Единая система: shell-card p-5 rounded-lg, nested form space-y-4, link-cards переехать выше под отдельный заголовок «Дополнительно».
HIGH H-4

EmptyState задвоен — два разных стиля для одного состояния

«Подключения не настроены»: в MCPConnectionList — голый <p>, в ChannelSelector — детальный warn-frame с CTA. На /insights — локальный EmptyState вместо глобального компонента.
Один EmptyState-prop API: icon / title / hint / cta. Удалить локальные дубли.
HIGH H-5

Тех-комбинатор: tailwind.config.ts — мёртвый

globals.css на v4-импорте, но @theme нет. Все утилиты bg-bg-1, duration-normal, ease-design-ease — no-op. Везде костыли bg-[var(--bg-1)].
Либо @theme inline { … } в globals.css, либо явно жить на arbitrary-class — но тогда удалить config файл и подменять inline style= на класс через font-mono в config.
HIGH H-6

Focus-ring 1px — недостаточно для WCAG и для людей с пониженным зрением

focus-visible:ring-1 ring-[var(--accent)] везде. На signal-orange в light-теме 1px теряется в фоне. --bg-hover undefined → keyboard-focused list items в dropdown без визуального состояния. Нарушение WCAG 2.4.7.
focus-visible:ring-2 ring-offset-2 ring-offset-[var(--bg-0)] ring-[var(--signal)]. Для chips и icon-buttons — outline-style box-shadow вместо ring (компактнее).
03

Логика и продуктовые пробелы

UI-баги — поверхность. Под ней — шесть мест, где логика приложения сообщает пользователю меньше, чем должна. Это не про красоту, это про доверие: аналитик не понимает, что происходит, и теряет уверенность в инструменте.

01 Streaming ответ — чёрный ящик
Сейчас: при отправке вопроса появляется «Загрузка…», через 12 секунд — готовый markdown. Пользователь не видит, что модель делает: думает / ищет / вызывает 1С / форматирует. Если зависнет — непонятно, на чём именно.
Вопрос → Думает... → Спрашивает 1С: getObjects(...) → Получено 24 записи → Ответ
Streaming stages с подписями шагов и таймингами (StreamingStages.tsx уже есть — подключить).
02 Channel selector не отвечает на главный вопрос
В dropdown'е показаны: имя, host:port, kind-badge, ping. Не показано главное — какая это конфигурация (УТ / ERP / УСО / самописная), сколько объектов в метаданных и когда последний раз обновлялся индекс.
A4F2 EMBEDDED ● ONLINE → УТ 11.5 2 134 объекта обновлено 5 мин назад
В dropdown-item добавить второй ряд: тип конфигурации, размер метаданных, last-sync (кэшировать в SQLite, refresh при focus).
03 Tool trace показывается раскрытым на полный JSON
Аналитик кликает «развернуть trace» — получает сырой json-tree с цветной подсветкой синтаксиса (purple/green/red, хардкод). Не понимает, что произошло: какая операция, сколько вернула, успешна ли.
JSON-tree свёрнутый → «Спросил у 1С: документы за май» 24 записи · 380 мс → [Показать JSON]
Двухуровневая модель: summary line («что сделал → что получил») + opt-in raw JSON по клику.
04 Backend недоступен — совет про docker compose up
На /settings: «Backend недоступен. Запустите docker compose up». В Electron-сборке Docker нет. Совет вводит в заблуждение. Indicator показывается в углу, но без действия.
Backend: недоступен → Что я могу сделать? [Перезапустить сервис] [Открыть лог]
Контекстный fix: в Electron — кнопка перезапуска локального backend. В dev — ссылка на лог. Без советов о Docker.
05 Onboarding из одного диалога — линейный, без возврата
OnboardingDialog — wizard вперёд. Нельзя вернуться, нельзя пропустить шаг и заполнить позже, нет состояния «ты уже всё настроил». Аналитик закрыл случайно — теряет прогресс.
Шаг 1 → Шаг 2 → Шаг 3 ↺ назад ⊘ пропустить ↻ сохранён prog
Stepper с back, skip, autosave в localStorage. Если пропустил — на главной чип «Завершите настройку (2/3)».
06 Удаление чата — window.confirm()
Native browser-confirm для удаления сессии. Выглядит как баг — внезапно появляется системный диалог поверх Stencil-интерфейса. Не уносит весь контекст (название сессии не в подписи), нет undo.
Удалить чат → Toast «Чат «A4F2 · продажи апрель» удалён» [Отменить] · 5 сек
Optimistic delete с undo-toast 5 сек. Только при undo-окно истекло → реальный DELETE.
