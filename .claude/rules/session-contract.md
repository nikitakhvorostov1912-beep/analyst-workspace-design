## Workflow «Продолжай» / «иди дальше по гсд»

При запросе на продолжение без конкретики:

1. Read `.planning/STATE.md` → текущая `milestone`, `phase`, `progress`
2. Read последний active/done `.planning/phases/*/PHASE-summary.md` (если есть)
3. Если active phase имеет `<N>-CONTEXT.md` — Read его
4. Озвучить в ОДНОМ сообщении: на чём остановились + следующая фаза по ROADMAP
5. Если есть прямая команда (как «иди до конца») — продолжать без пауз, делать атомарные коммиты
6. Если есть неопределённость — спросить (2-3 опции max)

## Правило 3 итераций (Матаков)

Если за 3 раунда без прогресса по задаче — STOP, передаём пользователю, переписываем руками.

Признаки исчерпания AI-цикла:
- Одни и те же ошибки повторяются в новых формулировках
- Каждый раунд чинит одно — ломает другое
- Эксперт знает решение лучше чем формулировка в ТЗ → задача недоопределена

Что делать после 3 раундов:
1. Стоп AI-цикл
2. Переформулировать задачу в Spec.md явно (acceptance criteria, out of scope)
3. Если переформулировка не помогла — писать руками
